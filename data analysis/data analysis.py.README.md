# Python Data Analysis

This is a beginner-level project in which I used Python to explore and analyze a biological gene expression dataset.

## Work Done
- Loaded the dataset using Python.
- Checked the number of rows and columns.
- Viewed the dataset structure and column names.
- Checked for missing values and duplicate data.
- Created graphs to understand the data.

## Tools Used
- Python
- Pandas
- Matplotlib

## Learning Outcome
Through this project, I am learning how to handle biological datasets, check data quality, and present data using graphs.
