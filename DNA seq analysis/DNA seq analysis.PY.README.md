# DNA Sequence Analysis using Python

This is a beginner-level project in which I used Python to analyze a DNA sequence and understand its basic composition.

## Work Done
- Calculated the length of the DNA sequence.
- Counted the number of A, T, G, and C bases.
- Calculated the GC percentage.
- Calculated the AT percentage.

## Tools Used
- Python

## Learning Outcome
Through this project, I learned how to use basic Python programming to analyze DNA sequences and understand their nucleotide composition.
