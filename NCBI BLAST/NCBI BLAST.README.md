# NCBI BLAST Practice

This is a beginner-level practice project in which I used NCBI BLAST to search and compare DNA sequences and understand the results.

## Work Done
- Retrieved a gene sequence from the NCBI database.
- Used BLAST to search for sequence similarities.
- Checked sequence identity and query coverage.
- Observed alignment results and E-values.
- Practiced understanding the similarity between DNA sequences.

## Tools Used
- NCBI Nucleotide Database
- NCBI BLASTN

## Learning Outcome
Through this practice, I learned how to search DNA sequences using NCBI BLAST and understand basic sequence comparison results.
