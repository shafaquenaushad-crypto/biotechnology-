# Biological Dataset Collection

This project focuses on finding and collecting biological data from online databases for learning and data analysis practice.

## Work Done
- Explored the NCBI GEO database.
- Selected a biological gene expression dataset.
- Collected dataset files for further analysis.
- Reviewed basic information about the dataset, including its title, samples, and data type.

## Tools Used
- NCBI GEO
- GEO accession: GSE348919

## Learning Outcome
Through this project, I learned how to find biological datasets, understand their basic information, and prepare data for further analysis.
