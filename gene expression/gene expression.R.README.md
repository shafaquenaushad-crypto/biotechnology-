# Gene Expression Data Analysis using R

This is a beginner-level project in which I used R to explore and analyze a gene expression dataset.

## Work Done
- Loaded the dataset into R.
- Checked the number of rows and columns.
- Viewed the dataset structure and column names.
- Checked for missing values and duplicate data.
- Checked gene expression values.
- Practiced understanding and interpreting biological data.

## Tools Used
- R
- RStudio

## Learning Outcome
Through this project, I am learning how to work with gene expression data, check data quality, and understand biological datasets using R.
