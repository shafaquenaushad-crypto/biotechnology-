# Zoology Practical File

This folder contains my zoology practical work completed as part of my B.Sc. Life Science studies.

## Practical Work
- Measurement of pre-clitellar and post-clitellar lengths in earthworms.
- Calculation of mean, median, mode, and standard deviation.
- Sequence analysis using NCBI BLAST.
- Introduction to phylogenetic analysis using PHYLIP.

## Learning Outcome
Through these practicals, I learned basic biological measurement, statistical calculations, sequence analysis, and methods used in studying evolutionary relationships.
