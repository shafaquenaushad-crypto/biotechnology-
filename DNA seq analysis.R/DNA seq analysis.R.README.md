# DNA Sequence Analysis using R

This is a beginner-level project in which I used R to study the composition of a DNA sequence.

## Work Done
- Counted the number of A, T, G, and C bases.
- Analyzed the nucleotide composition.
- Generated the complementary DNA sequence.
- Practiced working with DNA sequences using R.

## Tools Used
- R
- RStudio

## Learning Outcome
Through this project, I learned how to use basic R programming for DNA sequence analysis and understand the complementary base pairing of DNA.
