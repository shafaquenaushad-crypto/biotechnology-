# Bioinformatics Internship

This folder contains my work and learning during my bioinformatics internship at Swynex. I explored biological data collection, basic data analysis, and the presentation of results using tables and graphs.

This experience helped me understand how computational methods can support biotechnology research and the study of biological data.

## Skills Practised
- Biological data collection
- Basic data analysis
- Data visualization
- Biological data interpretation

## Purpose
To understand the role of bioinformatics in biotechnology and develop basic skills for biological research.
